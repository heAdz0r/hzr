# HZR 0.8.0 integration verification — 2026-09-05

## Scope

This report records the integrated source candidate on `codex/0.8.0-integration`.
The fresh audit used current source and runtime evidence; previous PRDs were not used as its findings.
The user approved P0/P1 implementation, the visualizer redesign, and then inclusion of the completed
P2 branch `feat/prd-p2-agent-efficiency` (`9016b29`). That commit is an ancestor of this branch.

The implementation checkpoint is `0f2f8ca`, P2 integration is `6689376`, and P2 release-note
documentation is `44cd601`. Subsequent correctness fixes and this report belong to the final
verification commit. The workspace version is 0.8.0; the installed runtime was not upgraded.

## Measurement and rollout boundaries

The seven-day audit remains a frozen pre-change baseline. Its byte estimates and reread heuristic
are not a post-change experiment. Source tests establish supported behavior, not lower total task
cost, provider billing savings, or SoTA quality.

No real user integration was reinstalled, no existing foreign process was killed, and no paid
model evaluation ran. Source preparation and an isolated local bundle do not publish a release.
Tag/push, CI and all supported native artifacts/checksums, installed-host probes and the paired
accepted-task evaluation remain separately verifiable release/rollout steps.
