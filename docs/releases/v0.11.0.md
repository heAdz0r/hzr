# HZR 0.11.0

The managed command engine is synced with upstream RTK v0.50.0 (fork-core `0.50.0-fork.1`),
and the sync was used to find where filtered commands answered differently from the native
ones. Each case below was reproduced on the 0.10.x engine first and is now covered by a
regression test and by `scripts/upstream-parity-probe.sh` (22 native-vs-filtered cases).

## Commands that answer what you asked

- `diff a b` printed both files and exited 0 when one line changed. It is now the native
  `diff` with your flags and exit code (1 when files differ), bounded on large outputs with
  the exact recovery command.
- `grep -m 1`, `grep -l`, `grep -v`, `grep -h`, `rg -u`, `diff -u`, `ls -h` reach the tool.
  rtk's own options were capturing them; `grep -v` returned the matches instead of the rest.
- `gh pr checks` shows which checks failed when a check fails (it printed nothing), and
  counts cancelled and skipped runs.
- `find` on a missing path reports the error and exits 1; `find src` lists `src` instead of
  searching for files named "src"; hidden and gitignored matches are disclosed.
- `head`/`tail` return the native bytes: CRLF, a missing final newline and non-UTF-8 text
  survive, and bare `head file` is ten lines, not the whole file.
- `git status` from a subdirectory prints paths relative to it; porcelain, `-z` and
  `git branch --format` output is git's bytes; a bare `git add` no longer stages everything;
  `git show --oneline -p <sha>` shows that commit, not HEAD; colour configuration no longer
  empties `git diff`; `git log` says when its default ten-commit limit hid older commits.

## Failures are never shown as success

`go build`, `next build` and `bun test` printed "Success" / "errors: 0" beside a non-zero
exit; `pnpm outdated` printed "All packages up-to-date" when pnpm failed; `tsc --version`
was replaced by a summary. The vitest, ESLint, playwright, pip and pnpm filters returned the
raw JSON report whenever the tool printed nothing else, because the JSON format rtk injects
was mistaken for your own protocol — they now summarise, with the exit code enforced.

## Interrupted commands keep their output

A signal to rtk while it captures output (a host timeout, Ctrl-C) is relayed to the command's
process group; the captured output is printed and rtk exits by the same signal, so
`timeout 60 cargo test` still reports 124 and shows how far the run got.

## Bun, Deno, pnpm

`bun.lock` is recognised and `bunx tsc` runs through bunx, not npx. `bun test` shows failures
and the tally from bun's own report. `deno lint`, `deno check` and `deno test` are compacted.
`pnpm --filter <pkg>`, `-r`, `-w` and `-C` are routed; `rtk vitest` accepts vitest's own
arguments (the rewritten `npx vitest run` failed when vitest was only installed locally) and
reads vitest 5's report file.

## Repositories stay clean

`hzr index init` and the daemon no longer leave `.grepai/` appended to a tracked
`.gitignore` (#22); the managed link is excluded through the local `info/exclude`.

Measured savings fall on the diff, grep, find, head/tail and git calls fixed above: they now
return native bytes where the previous rendering was a loss.
