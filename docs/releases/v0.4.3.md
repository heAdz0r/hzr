# HZR 0.4.3 — Efficient command utilization and accountable routing

HZR 0.4.3 completes the three-pass High Critical command-utilization correction.

- Existing first-class routes win over habitual managed RAW/proxy wrappers.
- Exact byte fidelity remains explicit and conservative when no equivalent bounded route exists.
- Top-level `hzr read` and `hzr write` expose the pinned typed operations directly.
- npm/pnpm test commands use their existing typed command families.
- `hzr stats --since <N{h|d|w}>` reports bounded family and mode panels with one time window.
- Requested mode, effective mode, actual search backend, fallback, and accounting stage are typed
  end to end without retaining query text, paths, arguments, file contents, or secrets.
- Managed Claude and Codex instructions reflect the complete current command/MCP surface and are
  repaired by the normal `init` lifecycle.

The audit reports UTF-8-size output estimates rather than provider-billed savings. See
[`20260821_command-surface-final_High-Critical.md`](../review/20260821_command-surface-final_High-Critical.md)
for the frozen snapshot, route inventory, acceptance criteria, and deferred command candidates.
Canonical upgrade guidance and the complete verification matrix are in the repository-root
`RELEASE_NOTES.md`.
