# HZR 0.8.5

HZR 0.8.5 fixes workspace discovery for projects without Git. A legacy
`~/.grepai/config.yaml` could previously make an unrelated project inherit the
entire home directory as its index root. Ownership checks then traversed files
outside the requested project and could fail on inaccessible directories,
leaving semantic retrieval unavailable.

Non-Git root discovery now stops before the home directory or filesystem root.
An index inside a project still owns that project's nested directories. Existing
home indexes and file permissions are preserved; traversal errors inside the
selected project remain errors.

After upgrading, run `hzr init --if-needed` from an affected project to create
its canonical managed index. The runtime remains the sole watcher owner.

Upgrade with `hzr update` after publication. This release does not change billing
measurements or claim additional token savings.
