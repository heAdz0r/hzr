# HZR 0.8.601

`hzr doctor` finishes even when one registered project's Git never answers.

Doctor walks every registered workspace and asks Git two questions about each:
whether the shared instruction file is tracked, and where the local exclude file
lives. Those probes inherited the terminal's stdin and had no deadline, so a
repository whose Git blocked — an unreachable volume, a credential helper
waiting for input, a stuck hook, a descendant holding the pipe open — stopped
the whole pass on that project with nothing reported. The diagnosis could only
be interrupted, never completed.

Each probe now closes stdin, disables terminal prompts, askpass helpers and
optional index locks, runs in its own process group, and is killed with that
group after 10 seconds. The timeout becomes a warning that names the project and
says what to check. One unresponsive project costs a single deadline, because
its remaining probes are refused as soon as the first one times out, and after
three unresponsive projects the rest of the fleet is reported without probing at
all.

This release changes no instruction file, index, workspace selection or token
accounting. A project that answers behaves exactly as before.
