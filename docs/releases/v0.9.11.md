# HZR 0.9.11

This release fixes execution interruptions during upgrades and lets doctor repair the duplicate OpenCode ICM ownership that previously required manual configuration changes.

## Doctor repairs the cause

Run `hzr doctor --fix --dry-run` to preview repairs, then `hzr doctor --fix` to apply them. Doctor disables direct ICM MCP registrations in OpenCode JSON/JSONC configuration with a retained backup, preserving comments and unrelated settings. It then sends SIGTERM only to a process whose full command matches the disabled registration and whose parent is OpenCode, rechecking the identity before signalling. Other clients and unrelated processes are left alone.

The repair starts an installed but inactive HZR daemon before reconciling accounting. Stale daemon-outage and fork-producer gaps are closed only after authenticated, version-compatible daemon health is available. Historical missing-operation evidence is retained: a recovered live session can return to complete coverage without pretending the earlier outage never happened. Unknown or unresolved failures remain visible.

OpenCode configuration is changed only by the explicit doctor repair; ordinary installation still leaves it alone. No memory databases are deleted or merged. If a client keeps a registration only in memory, restart that client and rerun doctor.

## Upgrades and execution

Long-lived adapters and runners keep the stable path through `current`, so an atomic upgrade does not pin subsequent commands to a removed release directory.

A planner spawn failure after successful engine validation uses a tracked raw route with no savings credit. Diagnostics identify the binary path. Timeouts and output-collection failures require approval; explicit policy denials, invalid plans and failed engine identity probes remain closed.

## Upgrade

Run `hzr update`, then `hzr doctor --fix`. Use `hzr stats` to confirm live accounting coverage. Doctor can still report separate warnings about unavailable workspaces or unverified host delivery; those are not evidence of a current accounting outage.
