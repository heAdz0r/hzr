# HZR 0.9.13

`hzr delegate` now runs in every repository. Repository rules larger than the
preload budget are preloaded head-first instead of refusing the run, and
`hzr doctor` reports what the delegated worker is actually given.

## Oversized repository rules no longer block delegation

Before this release, an `AGENTS.md` plus `CLAUDE.md` over 24576 bytes made every
delegated run in that workspace exit 1 with `project instructions exceed 24576
bytes`. No setting, flag or workspace override got past it, so delegation was
unavailable in exactly the repositories whose rules are worth following.

The 24 KiB limit is now a preload budget. Files share it: one that fits is
preloaded whole, and the remainder goes to the one that does not. A file that is
cut is cut on a line boundary, and the worker is told which sections were left
out:

```
<hzr_instructions_truncated file="CLAUDE.md" preloaded_bytes="19849" total_bytes="64643">
The rest of CLAUDE.md was not preloaded. Read it with hzr_read before acting on
any rule below the preloaded part.
Sections not preloaded: Deployment; Permissions; Migrations; ...
</hzr_instructions_truncated>
```

Nothing is hidden from the worker: the omitted rules stay one `hzr_read` away,
and the parent receives a preflight warning naming the exact split. A worker can
still act before it reads the rest, so a repository whose rules exceed the budget
should keep its decisive rules early in the file.

## Delegation readiness in `hzr doctor`

`delegation` reports the configured worker, its turn limit and deadline, and
names the command that supplies a missing credential.

`delegation_instructions` reports the bytes this workspace hands the worker,
warns when they exceed the preload budget, and fails on an instruction file the
bridge refuses. A symlinked instruction file is still refused: a worker never
follows rules from outside its workspace.

A managed-agent preflight failure now carries its remediation. A stale or
hand-edited engine bundle says to run `hzr update` or `hzr install --force`; an
unsupported Node says to replace it. A failed `hzr delegate` points at
`hzr doctor` instead of ending at the bridge symptom.

## Boundaries

File tools retain workspace confinement and shell tools retain HZR policy.
Worker completion remains distinct from parent acceptance, and provider-reported
usage is not a measured savings percentage.
