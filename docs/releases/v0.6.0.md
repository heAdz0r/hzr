# HZR 0.6.0

Released 2026-08-26.

HZR 0.6.0 unifies RTK fork-core, grepai, ICM, Caveman-derived agent execution, policy,
observability, and accounting behind one project-scoped control plane. It adds durable fidelity
reservations, strict anti-bypass routing, bounded engine supervision, a 13-tool typed MCP surface,
transactional adoption recovery, privacy-safe traces, and a project-isolated local observatory.

The complete release narrative and honest verification boundary are in
[`../../RELEASE_NOTES.md`](../../RELEASE_NOTES.md). Deferred mandatory gates were explicitly
excluded from the release claims.
