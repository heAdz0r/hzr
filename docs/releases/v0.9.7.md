# HZR 0.9.7

### Fixed

- `hzr stats` prices the money block again. The CLI kept an early return that withheld pricing whenever host delivery was unconfirmed — which, with no host acknowledging deliveries, was always — so the `ECONOMICS` table showed `unavailable` even with configured billing and an exact, loaded catalog row. The estimate is now priced and labelled with a delivery qualifier stating that only producer-side reductions are priced.

Upgrade with `hzr update`. Existing HZR data and billing selections are preserved.

The public-list estimate remains preliminary and is never summed with a billed receipt.
