# HZR 0.9.9

This release clears the last source of a permanent `LIVE DEGRADED` accounting state and closes a moderate dependency advisory.

## Accounting recovery

A fork-producer registration that produced no receipt within a day previously left its gap open forever: the daemon sweeper retired the abandoned context but kept the gap, so `hzr stats` reported `▲ LIVE DEGRADED` for operations that could never arrive. The sweeper now closes that gap when it retires the abandoned context, because no receipt can still arrive. Historical missing-operation counts are retained.

Run `hzr doctor --fix` to reconcile the same abandoned registrations left open by earlier versions, so an operator can clear the state immediately instead of waiting for the sweeper. Repair still requires an authenticated, version-compatible daemon health response; a still-running producer inside its pending grace is left alone.

## Dependencies

The Caveman bridge pins `adm-zip` 0.6.1, closing the moderate symlink-following advisory (GHSA-vwc7-r8mq-g2x9). The production dependency audit now reports zero vulnerabilities.

## Upgrade

Run `hzr update` to install this release. No new permission rules are installed, monitoring remains opt-in, and all historical accounting evidence is retained.

Verification includes the complete source/fork regression gate and native bundle/install checks.
