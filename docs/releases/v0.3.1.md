# HZR 0.3.1 — Verifiable local observability

HZR 0.3.1 upgrades the existing loopback visualizer into a typed operator surface.

## Highlights

- ICM FTS5-only retrieval is Ready when the managed service and read-only project snapshot pass.
- Interactive, privacy-safe project memory graph with bounded topics and relationships.
- grepai artifact freshness, full generation/fingerprint, managed watcher PID/uptime, and a
  cached semantic-only canary that does not manufacture ledger activity.
- Live project-scoped output operations with separate optimized/RAW routes, zero RAW savings
  credit, and first-class HZR replacement suggestions for avoidable bypasses.
- Provider receipts, selected-project activity, and global estimates remain separate.
- Vue UI remains part of `hzrd` at `http://127.0.0.1:47391/`; no new daemon or port.

## Truth and privacy

The dashboard exposes no memory content, semantic snippets, raw watcher logs, or database paths.
The activity stream covers fork-core output rows for the selected project and descendants; host
model prompts/responses are not claimed as observed unless explicitly attributed to HZR.

## Verification

Release acceptance includes workspace Rust format/Clippy/tests, deterministic fork-core gates,
Vue tests/type checking/build, installed bundle and engine attestation, live API checks, and
desktop/tablet/mobile browser QA.
