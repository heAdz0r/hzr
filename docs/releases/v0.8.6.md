# HZR 0.8.6

HZR updates now show what is happening and tolerate interrupted downloads.

The previous updater imposed a 120-second deadline on the entire release
archive. A working but slow connection could exceed that limit and fail without
showing any download progress. Archive transfers now use a 10-second connection
timeout and a 30-second idle-read timeout, with up to four attempts for transient
network and server failures. Within one update, interrupted transfers resume
from received bytes when supported; a server that ignores Range causes a clean
restart. Every completed archive must still match the published SHA-256.

Interactive terminals show animated stages and a download bar with received
bytes, percentage when the size is known, average speed and estimated remaining
time. The shell installer animates archive checks, extraction, agent setup and
service startup, retaining command output and errors. Redirected output stays
plain and JSON output has no animation.

Run `hzr update` to upgrade. The updater doing the download is the version
already installed: if an older updater still times out, use the verified
installer procedure in the README with tag `v0.8.6`. The new installer also
retries interrupted downloads. Partial downloads are not retained across
separate invocations.

This release does not change workspace selection or token accounting.
